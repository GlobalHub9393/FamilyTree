FASTEST UPLOAD (NO FOLDERS, ONE MULTI-FILE UPLOAD)
1. Download FamilyTree_GitHub_Ready.zip and extract/unzip it.
2. You will find 8 files to upload: index.html plus seven record_*.pdf files.
3. Open https://github.com/GlobalHub9393/FamilyTree
4. Add file > Upload files, and select/drag ALL 8 files together.
5. Commit changes to main.
6. Test https://globalhub9393.github.io/FamilyTree/
   Then Records & Research > click any record PDF.

All PDFs are stored at the same level as index.html. Do not upload the
ZIP itself to GitHub, because GitHub will not automatically unpack it.

Note: If the new HTML gets uploaded without the matching PDFs, the
record buttons will give a 404 until the seven record_*.pdf files exist.

Public distribution of third-party archival scans may require permission.
Retain the source citation and check reuse rights before posting publicly.
